LANDING PAGE · JOY LAPA (Cavazani · Minha Casa Minha Vida)
==========================================================

1) CONFIGURAÇÕES RÁPIDAS
------------------------
Abra js/main.js e preencha o bloco "EDITE AQUI" no topo:

  const CONFIG = {
    whatsapp: '5511945913535',   → número que recebe os leads (55 + DDD + número)
    creci: '',                   → ex.: 'Guerra · Corretor de imóveis · CRECI 000000-F'
                                   (aparece no rodapé; anúncio de imóvel deve ter o CRECI)
    metaPixelId: '2018343195510481', → ID do Pixel da Meta: SÓ OS NÚMEROS. Não cole o código
                                   <script> inteiro aqui: isso quebra a página (o código do
                                   Pixel já está pronto dentro do js/main.js).
                                   Com ele preenchido a página registra PageView, "Lead"
                                   no envio do formulário e "Contact" no botão de WhatsApp.
    mensagemPadrao: '...',       → texto dos botões de WhatsApp direto
    lancamento: {
      ativo: true,                 → false esconde a faixa de lançamento
      data: '24/10/2026',          → dia do lançamento (dd/mm/aaaa)
      hora: '00:00',               → hora em que a contagem zera (horário de Brasília)
      mostrarDepois: true,         → depois do dia D, mantém a faixa "Em lançamento"
    },
  };

FAIXA DE LANÇAMENTO (topo da página) — muda sozinha conforme a data:
  - Antes de 24/10: "Lançamento oficial · 24 de outubro" + contagem regressiva
    + botão "Entrar na lista VIP". O selo do topo vira "Lançamento em 24/10" e o
    formulário vira "Lista VIP do lançamento".
  - No dia 24/10: "É hoje! Lançamento oficial do Joy Lapa" + "Quero minha simulação".
  - Depois: "Joy Lapa em lançamento · consulte as condições" + "Simular agora".
  A mensagem que chega no WhatsApp também muda ("Quero entrar na lista VIP...",
  "Quero aproveitar o lançamento...") e o lead no Netlify Forms vem com o campo
  "fase" (Pré-lançamento / Dia do lançamento / Pós-lançamento).

  Para ver como a página fica em outra data, abra o site com:
    ?preview_lancamento=2026-10-24T10:00   (dia do lançamento)
    ?preview_lancamento=2026-10-25T10:00   (depois)
  Isso só muda o que VOCÊ vê; os visitantes continuam vendo a data real.


2) COMO FUNCIONA O FORMULÁRIO
-----------------------------
A pessoa preenche nome, WhatsApp, renda, FGTS e planta. Ao enviar:
  1. o lead é salvo no Netlify Forms (aba "Forms" do site na Netlify);
  2. o WhatsApp abre com a mensagem já preenchida, por exemplo:

     Olá! Quero simular o Joy Lapa.
     Nome: Maria
     WhatsApp: (11) 91234-5678
     Renda familiar: R$ 3.200 a R$ 5.000
     3+ anos de carteira (FGTS): Sim
     Planta de interesse: Select (2 dorms, 34 m²)

Mesmo que a pessoa desista de mandar a mensagem, o contato fica salvo na Netlify.
As UTMs do anúncio (utm_source, utm_campaign...) também vão junto no lead.

IMPORTANTE: em site novo, a Netlify vem com a detecção de formulários DESLIGADA.
Depois de publicar:
  Site configuration > Forms > "Enable form detection"
e publique de novo (arraste a pasta outra vez ou faça um push).
Para receber cada lead por e-mail: Forms > Form notifications > Add notification > Email.

Rodando no seu computador (python3 -m http.server) o salvamento não funciona
(dá erro 501), mas o WhatsApp abre normalmente. Na Netlify funciona tudo.


3) IMAGENS
----------
Todas as imagens saíram do book oficial (BOOK JOY LAPA.pdf) e estão em assets/img/.
  - Versão "-sm" (760 px) aparece na página; a versão grande (1400 px) abre ao clicar.
  - Para trocar uma imagem, mantenha o mesmo nome de arquivo.
  - og-image.jpg (1200 x 630) é a prévia que aparece quando o link é compartilhado.


4) PUBLICAR NA NETLIFY (pelo GitHub)
------------------------------------
O site tem uma função de servidor (API de Conversões, item 5). Ela só roda se o
site for publicado pelo GitHub; arrastar a pasta no Netlify Drop NÃO roda funções.

  1. Netlify > Add new site > Import an existing project > GitHub
     → repositório guerragestor-sudo/joylapa · branch main
     (deixe "Build command" vazio; "Publish directory" já vem do netlify.toml)
  2. Site configuration > Change site name → ex.: joylapa → https://joylapa.netlify.app
  3. Ative a detecção de formulários (item 2).
  4. Configure o token da API de Conversões (item 5).
  5. Deploys > Trigger deploy > Deploy site.

Depois disso, cada "git push" na branch main publica o site sozinho.

Se o endereço final NÃO for https://joylapa.netlify.app, troque no index.html:
canonical, og:url, og:image e twitter:image.


5) API DE CONVERSÕES DA META (CAPI)
-----------------------------------
Além do Pixel no navegador, o evento "Lead" também é enviado pelo servidor
(arquivo netlify/functions/lead.mjs). Isso recupera conversões perdidas por
bloqueador de anúncio, iPhone e navegação privada. Telefone e nome vão
criptografados (SHA-256). O Pixel e o servidor mandam o mesmo event_id, então
a Meta conta o lead UMA vez só (deduplicação).

O TOKEN NUNCA VAI NO CÓDIGO NEM NO GITHUB. Ele fica só na Netlify:

  Site configuration > Environment variables > Add a variable
    Key:   META_CAPI_TOKEN
    Value: (cole o token gerado no Gerenciador de Eventos)
    Marque "Contains secret values", se aparecer a opção.

Opcionais:
    META_PIXEL_ID          → padrão 2018343195510481 (só mude se trocar de Pixel)
    META_TEST_EVENT_CODE   → código de teste (ex.: TEST12345)

Depois de criar ou mudar variável, faça um novo deploy (Deploys > Trigger deploy).

COMO TESTAR:
  1. Gerenciador de Eventos > seu Pixel > Testar eventos: copie o código (TEST12345).
  2. Crie a variável META_TEST_EVENT_CODE com esse código e faça um novo deploy.
  3. Abra o site, preencha o formulário e envie.
  4. Na tela "Testar eventos" deve aparecer "Lead" vindo do Navegador e do Servidor,
     marcado como deduplicado.
  5. APAGUE a variável META_TEST_EVENT_CODE e faça outro deploy. Enquanto ela
     existir, os leads do servidor ficam só na aba de teste e não contam nas campanhas.

Se algo der errado: Netlify > Logs > Functions > lead. Os erros da Meta
aparecem lá com o prefixo [capi] (o token nunca é mostrado).

Proteções da função: só aceita chamadas vindas do próprio site, valida os dados
e limita a 10 envios por minuto por IP.


6) PONTOS PARA REVISAR ANTES DE ANUNCIAR
----------------------------------------
- Preços "a partir de" (R$ 229 mil / 249 mil / 299 mil) e "Escritura grátis":
  confirmar com a Cavazani se continuam valendo. O book também mostra uma
  tabela do Select de R$ 269.000; a página usa o menor valor (R$ 249.000).
- Garden: está como "Consulte" (o book não traz preço).
- Selo do Prime: o book usa ora 37 m², ora 38 m² (planta tipo A = 38,10 m²). A página usa 38 m².
- Regras do MCMV (faixas de renda, subsídio de até R$ 55 mil, juros a partir de 4% a.a.,
  tetos de R$ 275/400/600 mil) seguem a Portaria MCID nº 333/2026, em vigor desde abril/2026.
  Se o governo mudar as regras, atualize a seção "Minha Casa Minha Vida", o bloco FAIXAS
  em js/main.js e o FAQ.
- "5 min da Estação Lapa": o book indica 5 min DE BIKE, e a página diz isso.
- Benefícios "Indique e ganhe R$ 1.000" e "10% de desconto no boleto em dia": conferir regulamento.
- Rodapé: o texto legal diz que a venda só começa após o registro do memorial de incorporação.
  Quando sair o número do R.I., vale incluir no rodapé.
- CRECI: preencher no CONFIG (item 1).
