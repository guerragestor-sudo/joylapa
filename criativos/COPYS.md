# Criativos Joy Lapa: copys

Cada criativo tem dois arquivos:

- `feed/`: 1080×1350, para o feed do Facebook e Instagram e para mandar no WhatsApp (conversa ou lista de transmissão).
- `stories/`: 1080×1920, para Stories, Reels e status do WhatsApp. O conteúdo fica fora das áreas cobertas pelos botões do app.

Para cada criativo há:

- **Título:** o campo "Título" do anúncio na Meta (até 40 caracteres).
- **Anúncio:** o "Texto principal".
- **WhatsApp:** a mensagem para disparo, já com link rastreado. Troque `[nome]` pelo nome do contato.

Links:

- **No anúncio**, use o link do site com os parâmetros de URL do Gerenciador:
  `utm_source=meta&utm_medium=pago&utm_campaign={{campaign.name}}&utm_content={{ad.name}}`
- **No WhatsApp**, os links abaixo já vêm com `utm_source=whatsapp`. Assim os leads chegam marcados no Netlify Forms.
- **Domínio:** se o endereço do site não for `joylapa.netlify.app`, troque nos links.

## Como regerar as imagens
As artes são geradas a partir de `fonte/criativo.html`. Para mudar algum texto ou valor:

1. Edite `fonte/criativo.html`. No bloco "EDITE AQUI" ficam o CRECI e o número do registro da incorporação.
2. No Terminal, dentro da pasta `criativos`, rode `./gerar.sh` para gerar tudo, ou `./gerar.sh smart prime` para gerar só esses.

**Antes de anunciar:** quando sair o número do registro da incorporação (R.I.), preencha `registro` no bloco "EDITE AQUI" e gere de novo. A Lei 4.591/64 exige esse número nos anúncios do empreendimento.
